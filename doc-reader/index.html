Turn a PDF, Word, Markdown or text document into speech. Everything runs in this browser: your file never leaves your device.

How it works

  • PDFs are read with pdf.js. The text is rebuilt into paragraphs from line spacing, indents and font size, with running headers, page numbers and end-of-line hyphens removed.
  • Word files are read with mammoth.
  • Markdown is cleaned up before it is read: headings, list items and table rows become their own lines, while code blocks, images, link addresses and formatting marks are skipped. Plain text files are read as they are.
  • Speech comes from Gradium's open-weight Phonon 31M model, compiled to WebAssembly and run in a background worker. The 65 MB model downloads once, then loads from the browser cache.

English only for now. Scanned PDFs need OCR first, and old .doc files aren't supported.
